# examples/legacy/

Deprecated V1 Skill samples that use `skill.contract.js` and
`createOpenClawAdapter`.

Do **not** copy these for new work. Use
[`examples/js-eyes-skills/`](../js-eyes-skills/) (Skill Runtime V2:
`skill.manifest.json` + `skill.entry.js`) instead.

V1 discovery/activation remains supported until JS Eyes 4.0 for external
skills already in the field. Official skills no longer ship V1 adapters.
